# Kanban (Vue)

Канбан-доска для управления задачами. Проект создан на Vue 3 + Vite.

## Возможности

- Отображение задач в колонках по статусам: «Без статуса», «Нужно сделать», «В работе», «Тестирование», «Готово».
- Данные карточек хранятся в отдельном файле-моке `src/components/mocks/tasks.js` (поля: `id`, `topic`, `title`, `date`, `status`).
- Имитация загрузки данных: при первом запуске показывается сообщение «Данные загружаются», после чего карточки отображаются на доске.
- Попап пользователя: при клике на имя в шапке открывается окно с именем и почтой, закрывается при клике вне окна или по кнопке «Выйти».

## Установка и запуск

```sh
npm install
npm run dev
```

Сборка для продакшена:

```sh
npm run build
```

Проверка кода:

```sh
npm run lint
```

## Структура проекта

- `src/components/` — Vue-компоненты (шапка, доска задач, колонки, карточки, модальные окна)
- `src/components/mocks/` — тестовые данные для задач
- `src/router/` — роутер приложения
- `src/assets/` — стили
- `public/assets/` — статические изображения

## Компоненты

- `BaseHeader` — шапка с логотипом, кнопкой создания задачи и попапом пользователя
- `TaskDesk` — доска с колонками задач (имитация загрузки, фильтрация по статусам)
- `TaskColumn` — колонка задач
- `TaskCard` — карточка задачи
- `TaskModal` — модальное окно просмотра задачи
- `NewCardModal` — модальное окно создания задачи
- `ExitModal` — модальное окно выхода из аккаунта
