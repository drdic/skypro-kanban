# Kanban (Vue)

Канбан-доска для управления задачами. Проект создан на Vue 3 + Vite + Vue Router.

## Возможности

- Отображение задач в колонках по статусам: «Без статуса», «Нужно сделать», «В работе», «Тестирование», «Готово».
- Данные задач загружаются через API Skypro (`https://wedev-api.sky.pro/api/kanban`), а не из моков.
- Авторизация через API Skypro (`https://wedev-api.sky.pro/api/user`): вход, регистрация, выход.
- Окно пользователя: при клике на имя в шапке открывается попап с именем и почтой, закрывается при клике вне окна.
- Календарь при создании/редактировании задачи: переключение месяцев и выбор дня.
- Роутинг между страницами: главная, вход, регистрация, просмотр/редактирование карточки, добавление задачи, выход, страница 404.
- Защищённые маршруты: неавторизованный пользователь перенаправляется на страницу входа.
- Авторизация сохраняется при перезагрузке страницы (данные пользователя хранятся в `localStorage`).
- Общее состояние приложения передаётся через `provide` / `inject` в `AppLayout` (пользователь и задачи доски).

## Установка и запуск

```sh
npm install
npm run dev
```

Сборка для продакшена:

```sh
npm run build
```

Проверка кода:

```sh
npm run lint
```

Публикация на GitHub Pages:

```sh
npm run deploy
```

## Маршруты

| Путь | Страница |
|------|----------|
| `/` | Доска с карточками |
| `/login` | Вход |
| `/register` | Регистрация |
| `/card/:id` | Просмотр и редактирование карточки |
| `/add` | Добавление новой задачи |
| `/exit` | Выход из аккаунта |
| `*` | Страница 404 |

## Структура проекта

- `src/layout/` — общий макет (`AppLayout.vue`), через который передаются общие данные
- `src/components/` — Vue-компоненты (шапка, доска задач, колонки, карточки, модальные окна)
- `src/views/` — страницы приложения
- `src/router/` — роутер приложения (вложенные маршруты)
- `src/services/` — запросы к API (авторизация и задачи)
- `src/assets/` — стили и изображения
- `public/assets/` — статические изображения

## Архитектура

Общее состояние приложения (пользователь и задачи доски) хранится в `AppLayout` и передаётся дочерним компонентам через `provide` / `inject`. Это избавляет от «пропс-дрилинга» и дублирования кода.

## Компоненты

- `AppLayout` — общий макет, хранит состояние пользователя и задач, рендерит вложенные страницы через `RouterView`
- `BaseHeader` — шапка с логотипом, кнопкой создания задачи и попапом пользователя
- `TaskDesk` — доска с колонками задач (загрузка с API, фильтрация по статусам)
- `TaskColumn` — колонка задач
- `TaskCard` — карточка задачи (ссылка на страницу карточки)
- `TaskModal` — окно просмотра/редактирования задачи
- `NewCardModal` — окно создания задачи
- `ExitModal` — окно выхода из аккаунта
