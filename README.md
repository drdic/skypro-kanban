# Kanban (Vue)

Канбан-доска для управления задачами. Проект создан на Vue 3 + Vite + Vue Router, данные
загружаются с API Skypro.

## Возможности

### Основной функционал

- **Доска задач** — задачи отображаются в пяти колонках по статусам: «Без статуса», «Нужно
  сделать», «В работе», «Тестирование», «Готово».
- **Создание задачи** — форма с названием, описанием, категорией («Web Design», «Research»,
  «Copywriting») и выбором даты в календаре с переключением месяцев.
- **Просмотр и редактирование карточки** — модальное окно с возможностью изменить название,
  описание, категорию, статус и дату. Изменения мгновенно отражаются на доске.
- **Удаление задачи** — удаление карточки с обновлением списка на доске.
- **Авторизация и регистрация** — вход, регистрация и выход через API Skypro. Данные
  пользователя и токен сохраняются в `localStorage`, поэтому сессия не теряется при
  перезагрузке страницы.
- **Защита маршрутов** — неавторизованный пользователь не может попасть на главную страницу:
  глобальный навигационный guard перенаправляет его на страницу входа.
- **Категории с цветовой индикацией** — каждая категория имеет свой цвет, который применяется
  к бейджу в карточке и в шапке модального окна задачи.
- **Роутинг** между страницами: главная, вход, регистрация, карточка задачи, добавление задачи,
  выход, страница 404.

### Обработка ошибок и валидация

- **Валидация форм** — нельзя отправить пустые поля или значения из одних пробелов (`.trim()`),
  название задачи проверяется на минимальную длину.
- **Ошибки сервера** — пользователь видит текст ошибки, полученный от сервера, прямо в форме
  и в уведомлении.
- **Падение сервера и сети** — все запросы обёрнуты в единый обработчик: для ошибок 5xx
  показывается «Сервер недоступен. Попробуйте позже», при отсутствии сети — «Нет соединения
  с сервером. Проверьте подключение к интернету».
- **Истёкшая сессия** — при ответе 401 пользователь разлогинивается и перенаправляется на вход.
- **Повтор запроса** — при ошибке загрузки доски показывается сообщение и кнопка
  «Попробовать снова».
- **Чистая консоль** — в проекте нет `console.*`, `debugger`, неиспользуемых переменных и
  лишних комментариев.

### UX-доработки

- **Уведомления (тосты)** — при успехе и ошибке операций всплывают информативные уведомления
  (создание, редактирование, удаление задачи, вход, регистрация, выход, ошибки сервера).
- **Блокировка кнопок во время запроса** — кнопки отправки недоступны и показывают состояние
  загрузки («Создание...», «Вход...»), что исключает повторную отправку.
- **Скелетон-загрузка** — вместо надписи или спиннера отображается анимация мерцающих
  карточек-заглушек. Число и расположение заглушек повторяет последнюю раскладку доски
  (сохраняется в `localStorage`), поэтому переход к реальным данным проходит без скачков.
- **Пустое состояние** — если задач нет, отображается надпись «Новых задач нет» с подсказкой
  и ссылкой на создание задачи, без ошибок в консоли.
- **Страница 404** — оформлена в общем стиле (шрифт Roboto, цвета из темы), содержит ссылки
  «Вернуться на главную» и «Вернуться назад».

### Дополнительные фичи (VueUse)

- **Смена темы** — реализована через `useDark` из `@vueuse/core`. Переключатель «Тёмная тема»
  находится в попапе пользователя в шапке. Выбранная тема сохраняется и применяется до первой
  отрисовки страницы, поэтому вспышки светлой темы при перезагрузке нет. Тёмная палитра
  описана CSS-переменными в `src/assets/theme.css`.
- **Закрытие попапа по клику вне окна** — реализовано через `onClickOutside`, попап профиля
  закрывается при клике за его пределами.
- **Закрытие попапа по клавише Escape** — реализовано через `onKeyStroke('Escape')`.

## Установка и запуск

```sh
npm install
npm run dev
```

Сборка для продакшена:

```sh
npm run build
```

Проверка кода:

```sh
npm run lint
```

Форматирование файлов:

```sh
npm run format
```

Публикация на GitHub Pages:

```sh
npm run deploy
```

## Маршруты

| Путь          | Страница                          | Доступ        |
| ------------- | --------------------------------- | ------------- |
| `/`           | Доска с карточками                | Только авторизованным |
| `/login`      | Вход                              | Публичная     |
| `/register`   | Регистрация                       | Публичная     |
| `/card/:id`   | Просмотр и редактирование карточки| Только авторизованным |
| `/add`        | Добавление новой задачи           | Только авторизованным |
| `/exit`       | Выход из аккаунта                 | Только авторизованным |
| `*`           | Страница 404                      | Публичная     |

## Структура проекта

- `src/layout/` — общий макет (`AppLayout.vue`), через который передаются общие данные
- `src/components/` — Vue-компоненты (шапка, доска задач, колонки, карточки, модальные окна,
  уведомления)
- `src/views/` — страницы приложения
- `src/router/` — роутер приложения (вложенные маршруты и guard авторизации)
- `src/services/` — запросы к API (авторизация и задачи) с единой обработкой ошибок
- `src/assets/` — глобальные стили (`theme.css` с переменными тем, `main.css`)
- `public/assets/` — статические изображения (в т.ч. картинка для страницы 404)

## Архитектура

- Общее состояние приложения (пользователь, задачи доски, уведомления) хранится в `AppLayout`
  и передаётся дочерним компонентам через `provide` / `inject`. Это избавляет от
  «пропс-дрилинга» и дублирования кода.
- Запросы к API вынесены в `src/services` и возвращают нормализованную ошибку с сообщением
  и HTTP-статусом, что позволяет компонентам показывать понятный текст и обрабатывать 401.
- Тема оформлена CSS-переменными: светлая палитра в `:root`, тёмная — в классе `.dark`.

## Компоненты

- `AppLayout` — общий макет, хранит состояние пользователя, задач и уведомлений, рендерит
  вложенные страницы через `RouterView`
- `BaseHeader` — шапка с логотипом, кнопкой создания задачи, попапом пользователя и
  переключателем тёмной темы
- `BaseToast` — всплывающие уведомления об успехе и ошибках
- `TaskDesk` — доска с колонками задач (загрузка с API, фильтрация по статусам, скелетон,
  пустое состояние, обработка ошибок)
- `TaskColumn` — колонка задач
- `TaskCard` — карточка задачи (ссылка на страницу карточки)
- `TaskModal` — окно просмотра/редактирования/удаления задачи
- `NewCardModal` — окно создания задачи
- `ExitModal` — окно выхода из аккаунта
